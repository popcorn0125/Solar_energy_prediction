# Solar_energy_prdiction
대구가톨릭대학교 [AI DX 전문가 교육 프로그램] 팀 프로젝트 - 태양광 전력 생산량 예측

# 기상 데이터를 활용한 태양광 발전 효율 예측 AI 모델

## 1. 프로젝트 개요
기상 조건에 따른 실시간 태양광 발전 효율을 예측하여, 전력망의 안정성을 높이고 개별 가정의 고전력 가전(에어컨, 세탁기 등) 사용 시점을 최적화하는 프로젝트입니다.

## 2. 배경 및 문제 정의
* 국내 자가용 태양광 설비 용량은 2015년 671MW에서 2024년 4,620MW로 약 7배 급증했습니다. (출처: [기후에너지환경부 김위상 의원실 제출 자료](https://www.chosun.com/economy/industry-company/2026/01/23/42EMZCKM6ZCP3POHWJMF5OHCE4/).)
* 자가용 태양광은 한전 계량기에 잡히지 않는 전력입니다. 날씨 급변으로 자가 발전이 멈출 경우, 숨겨져 있던 전력 수요가 순간적으로 한전 전력망에 몰려 블랙아웃 등 심각한 수급 위기를 초래할 수 있습니다. 이를 예방하기 위해 개별 발전량의 정확한 예측 시스템이 필수적입니다.

## 3. 사용 데이터
* **기상 데이터:** 기상청 기상자료개방포털(ASOS) 대구광역시 시간별 관측 데이터 (2023~2024)
* **발전량 데이터:** 한국전력거래소(KPX) 대구광역시 시간별 태양광 발전량 (2023~2024)
* **입력 변수(X):** 월, 시간, 기온, 강수량, 풍속, 습도, 일사량, 전운량 (총 8종)

## 4. 핵심 접근법: 발전 효율 정규화
* 본 프로젝트 데이터 분석 결과, 대구 지역 태양광 최대 발전량은 2023년 대비 2024년에 약 1.42배 증가했습니다.
* 기존 모델처럼 '절대 발전량(kWh)' 수치 자체를 학습시킬 경우, 연도별 설비 증가분을 반영하지 못해 과소 혹은 과대 예측이 발생합니다.
* **해결책:** IEC 61724 국제 표준에 착안하여, 절대값이 아닌 '발전 효율(%)'을 타겟 변수로 정규화하여 학습했습니다.
    * `공식: 시간별 발전 효율 = 시간별 실제 발전량 / 해당 연도의 최대 발전량`
* 효율을 학습한 모델은 설비 규모와 무관하게 기상에 따른 패널의 물리적 반응 법칙을 파악합니다. 따라서 사용자의 개별 설비 용량(예: 3kW)만 곱해주면 즉시 맞춤형 예측이 가능한 높은 확장성을 가집니다.

## 5. 모델 성능 비교 (2024년 학습 → 2023년 검증)
모델의 확장성과 신뢰성을 검증하기 위해, 온전한 2024년 데이터로 모델을 학습시키고 2023년 데이터로 평가하는 교차 검증을 수행했습니다.

* **검증 전략 설계 이유:**
    1. **데이터 무결성 확보:** 2023년 데이터 중 2월 데이터가 결측되어 있어, 4계절의 기상 패턴이 완벽하게 수집된 2024년(1년치) 데이터를 모델 학습의 기준으로 삼았습니다.
    2. **장기 예측 신뢰도 검증:** 1년 전체 주기를 온전히 학습하고 다른 1년 전체 구간을 테스트함으로써, 특정 계절에 편향되지 않은 모델의 범용성과 예측 신뢰도를 극대화했습니다.

### 5.1 효율 변환 전 (절대 발전량 학습)
2024년 추정 설비 용량(Train): 62973.67 kWh <br>
2023년 추정 설비 용량(Test) : 44386.73 kWh

* 결정 계수 (R2 Score): 0.8106
* 전체 오차 (RMSE): 5,224.98 kWh (대구시 전체 기준)
* 3kW 기준 평균 오차 (RMSE): 0.2489 kWh
* 2024년의 큰 설비 규모를 기준으로 학습한 AI가 2023년의 작은 설비 규모를 예측하게 되므로, 패턴은 유사할지라도 체급 차이를 인지하지 못해 실제 발전량과 오차가 발생합니다.

### 5.2 효율 변환 후 (발전 효율 정규화 학습)
* 결정 계수 (R2 Score): 0.9003
* 전체 오차 (RMSE): 3,790.36 kWh (대구시 전체 기준) (효율 오차 약 9%)
* 3kW 기준 평균 오차 (RMSE): 0.2562 kWh (설비 용량 대비 오차율 약 8.5%)
* 발전 패턴 정확도를 90%까지 끌어올렸으며, 전체 오차를 기존 대비 약 1,434 kWh 이상 대폭 감소시켰습니다. 가정용 3kW 패널 기준 시간당 오차는 0.25 kWh(오차율 약 8.5%)로 확인했습니다.
